# actions

Shared GitHub Actions and automation workflows for `ajxcodes` repositories.

## Overview

This repository houses centralized composite actions and workflows used across projects. Documentation and usage instructions will be populated as actions are merged into `main`.

## Actions

| Action | Description | Status |
| :--- | :--- | :--- |
| `ai-pr-reviewer` | Automated pull request code review powered by Google Gemini and GitHub GraphQL | *Planned* |
| `auto-tag` | Automated SemVer tagging and release generation based on Conventional Commits | *Planned* |
